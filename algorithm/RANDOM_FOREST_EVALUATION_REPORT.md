# 随机森林算法评测与改进报告

- 评测日期：2026-11-10
- 数据集：UCI Cleveland 心脏病数据，项目内置 `cleveland.csv`
- 数据指纹：`6fc56fce71d47cf6`
- 样本量：303，其中阳性 139（45.9%），阴性 164（54.1%）
- 特征：13 个，含 8 个分类字段和 5 个数值字段
- 缺失：`ca` 4 条、`thal` 2 条。缺失值在每个训练折内以众数填补，分类变量在训练折内独热编码
- 当前参数：400 棵树、`min_samples_leaf=3`、`max_features=sqrt`、`class_weight=balanced`、随机种子 42
- 验证方式：5 折分层交叉验证。所有报告指标均来自交叉验证预测，未使用训练集内预测结果

## 1. 评测结果

### 1.1 区分能力与概率质量

| 指标 | 结果 | 解读 |
|---|---:|---|
| ROC-AUC | 0.9155 | 区分阳性与阴性的能力较强 |
| PR-AUC | 0.9096 | 在当前 45.9% 阳性率下，精确率-召回率表现较好 |
| Brier score | 0.1207 | 概率误差仍有优化空间，越低越好 |
| 校准截距 | -0.0630 | 总体预测概率略偏低 |
| 校准斜率 | 1.4417 | 概率分布偏保守，存在过度收缩，建议校准 |

5 折 ROC-AUC 分别为 0.9416、0.8929、0.9102、0.9147、0.9308，均值为 0.9180，样本标准差为 0.0193。最低折与最高折相差 0.0487，说明小样本下仍有一定方差。

## 2. 结论

1. 当前随机森林的排序能力达到可用水平，ROC-AUC 约 0.92，明显优于多数类基线。
2. 若把“准确性”理解为 0.5 阈值下的 Accuracy，当前约为 82.8%，Balanced accuracy 约为 82.6%。不能只用 ROC-AUC 代替准确率。
3. Sensitivity 为 79.1%，仍有 20.9% 的阳性样本在该阈值下被漏判。医疗筛查场景不能直接把 0.5 作为最终阈值，应结合漏诊成本选阈值。
4. 概率校准是当前主要短板。校准截距和斜率显示预测概率存在系统性偏差，不能把输出概率直接当作临床风险概率使用。
5. 303 条样本只能支持内部验证。当前结果不能代表外部医院、不同人群或真实部署场景的泛化性能。

## 3. 改进方案

### 优先级 A：先修复评测和工程基础

- 修复 `algorithm/regression.py` 为空导致的包导入失败。当前标准 `unittest` 发现阶段会在导入 `algorithm` 时失败，评测链路无法作为持续集成门禁。
- 固定并记录数据指纹、随机种子、折分方案、参数和软件版本。
- 增加重复分层交叉验证或 bootstrap 置信区间，避免只报告单次 5 折结果。
- 保留独立测试集或按时间、机构划分的外部验证集，禁止用同一份小数据反复调参后再报告同一折结果。

### 优先级 B：改进临床判定性能

- 基于临床代价选择阈值。筛查优先提高 Sensitivity，确诊辅助可增加 Specificity。报告阈值-敏感度-特异度-PPV-NPV 曲线，而不是只报 0.5 阈值。
- 对随机森林概率做 Platt scaling 或 isotonic calibration。校准器必须嵌套在交叉验证训练折内，避免校准数据泄漏。
- 同时报告 ROC-AUC、PR-AUC、Brier score、校准曲线和决策曲线分析。

### 优先级 C：在不改变数据口径的情况下调参

- 在嵌套交叉验证中搜索 `n_estimators`、`max_depth`、`min_samples_leaf`、`max_features` 和 `class_weight`。
- 以 PR-AUC、Sensitivity 下的 Specificity 或临床效用作为选择目标，不要只优化 Accuracy。
- 对类别变量保留当前独热流程，并比较原生类别编码、目标编码和 CatBoost/梯度提升树等候选模型。所有编码必须在训练折内完成。
- 使用按原始字段聚合的 permutation importance，并用 SHAP 检查方向、交互和个体级解释的一致性。

### 优先级 D：验证泛化与公平性

- 在外部数据上验证年龄、性别、胸痛类型和缺失模式变化下的性能。
- 分层报告不同性别、年龄段和缺失状态的 Sensitivity、Specificity、AUC 与校准误差。
- 明确模型是研究性风险分层工具，不能替代医生诊断或单独用于临床决策。

## 4. 当前实现中的工程问题

优先级 A 已完成。已恢复 `regression.py` 与 `nested_validation.py` 的可导入接口，`algorithm` 包现在可以正常导入，标准算法测试已通过 33 项。随机森林结果中的数据指纹、参数、折数和随机种子原本已结构化记录，现已可通过正常包入口读取。当前回归模块使用项目已有依赖实现基础 Logistic 回归和交叉验证，不引入 Qt 或额外统计依赖。

优先级 B 已完成。随机森林结果现在额外提供折内 Platt 校准后的 ROC-AUC、PR-AUC 和 Brier score，提供 0.2–0.8 阈值表，以及与“全部干预”和“全部不干预”基线可比较的决策曲线净获益。校准器只在每个外层训练折内拟合，避免使用外层验证样本拟合校准器。阈值表字段依次为阈值、Accuracy、Sensitivity、Specificity、PPV、NPV 和 F1。默认阈值仍保留为 0.5，临床使用时应由预先声明的漏诊成本选择阈值。

## 5. 建议验收标准

- CI 能完整执行数据、算法和 UI 相关测试。
- 重复交叉验证报告 ROC-AUC、PR-AUC、Accuracy、Balanced accuracy、Sensitivity、Specificity、F1、MCC、Brier score 及置信区间。
- 阈值由预先声明的临床目标确定，并在独立验证集锁定。
- 外部验证集上同时达到预先约定的区分、校准和安全性指标。
