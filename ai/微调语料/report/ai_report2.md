# Cleveland 心脏风险数据分析报告

## 摘要
本报告基于 Cleveland 数据集共 303 例样本，对心脏病阳性率及相关特征进行描述性分析。

结果显示：样本平均年龄 54.4 岁（范围 29–77 岁），心脏病阳性 139 例，阳性率 45.9%。分组比较中，阳性组平均年龄、静息血压、胆固醇均高于阴性组，而最大心率低于阴性组。年龄分层显示 51–70 岁人群阳性率较高（50.8%–58.9%），胸痛类型 4 的阳性率达 72.9%。

声明：本报告仅为描述性统计结果，不构成任何诊疗结论或因果推断。

## 方法
- 数据来源：Cleveland 数据集，共 303 条记录、5 个分组。
- 分析类型：心脏病风险描述性分析（非建模、非预测验证）。
- 分析内容：总体阳性率、年龄分层阳性率、风险因素比例、阳性组与阴性组组间均值比较、连续特征分布（最小值、四分位数、中位数、最大值）。
- 指标定义：阳性率指目标变量为阳性（患病标签=1）的样本占比；组间差值指阳性组均值减阴性组均值。
- 说明：本报告未包含模型训练、显著性检验或因果分析，相关结论无法从现有结果中确定。

## 关键结果

### 1. 总体情况
- 样本量：303 例
- 阳性例数：139 例
- 阳性率：45.9%（139 / 303）
- 平均年龄：54.4 岁（范围 29–77 岁）
- 平均静息血压：131.7 mmHg（阴性组 129.3 mmHg）

### 2. 年龄分层阳性率
- 0–40 岁：18 例，阳性 6 例（33.3%）
- 41–50 岁：76 例，阳性 23 例（30.3%）
- 51–60 岁：130 例，阳性 66 例（50.8%）
- 61–70 岁：73 例，阳性 43 例（58.9%）
- 71–77 岁：6 例，阳性 1 例（16.7%）
（注：51–70 岁两个年龄段阳性率升至 50.8%–58.9%；71–77 岁组样本仅 6 例，其阳性率（16.7%）的稳定性有限，解释需谨慎。）

### 3. 风险因素比例
- ST 压低大于 0：67.3%（204例）
- 主要血管数大于 0：41.1%（123 / 299例）
- 运动诱发心绞痛：32.7%（99例）
- 空腹血糖异常：14.9%（45例）

### 4. 阳性组与阴性组组间比较（阳性 vs 阴性）
- 年龄：56.6 岁 vs 52.6 岁（差值 +4.0）
- 静息血压：134.6 mmHg vs 129.3 mmHg（差值 +5.3）
- 胆固醇：251.5 mg/dL vs 242.6 mg/dL（差值 +8.8）
- 最大心率：139.3 bpm vs 158.4 bpm（差值 -19.1）

### 5. 连续特征分布（最小值 / Q1 / 中位数 / Q3 / 最大值）
- 年龄（岁）：29.0 / 48.0 / 56.0 / 61.0 / 77.0
- 静息血压（mmHg）：94.0 / 120.0 / 130.0 / 140.0 / 200.0
- 胆固醇（mg/dL）：126.0 / 211.0 / 241.0 / 275.0 / 564.0
- 最大心率（bpm）：71.0 / 133.5 / 153.0 / 166.0 / 202.0
- ST 压低（mV）：0.0 / 0.0 / 0.8 / 1.6 / 6.2

### 6. 性别与胸痛类型
- 性别：男性阳性率 55.3%，女性阳性率 25.8%。
- 胸痛类型：类型 4 阳性率最高，为 72.9%。

## 解释
- 总体阳性率：样本中约 45.9% 为阳性，说明该数据集阳性与阴性样本接近均衡，但该比例仅反映本数据集构成，不能外推为人群患病率。
- 年龄：阳性组平均年龄比阴性组高 4.0 岁；年龄分层中 51–70 岁阳性率较高，提示年龄与阳性标签在本样本中存在描述性关联。该关联不代表因果关系。
- 最大心率：阳性组最大心率比阴性组低 19.1 bpm，是本报告中组间差值最大的指标之一，属于描述性差异，其统计学意义未在现有结果中给出。
- 血压与胆固醇：阳性组静息血压（+5.3 mmHg）与胆固醇（+8.8 mg/dL）均略高于阴性组，差值幅度较小，需结合分布与样本量谨慎解读。
- 风险因素比例：ST 压低大于 0 的比例最高（67.3%），其次为主要血管数大于 0（41.1%）与运动诱发心绞痛（32.7%）；空腹血糖异常比例最低（14.9%）。这些比例描述的是样本构成，不是风险预测结论。
- 性别与胸痛类型：男性阳性率高于女性，胸痛类型 4 阳性率最高，均为分组描述性结果；胸痛类型与性别之间的混杂关系未在现有结果中分析，无法确定。

## 局限性
- 仅描述性分析：未进行模型训练、交叉验证或预测性能评估，无法给出预测准确性、敏感度、特异度等指标。
- 无显著性检验：组间差值（如年龄 +4.0 岁、最大心率 −19.1 bpm）未提供置信区间或 P 值，无法判断差异是否具有统计学意义。
- 无因果推断：所有关联均为样本内描述性关联，不能解释为风险因素与疾病的因果关系。
- 样本量与分层稳定性：71–77 岁组仅 6 例，该层阳性率（16.7%）稳定性有限；主要血管数指标分母为 299（非 303），存在少量缺失，缺失机制未在结果中说明。
- 单数据集：结果仅基于 Cleveland 数据集，未做外部验证，外推性受限。
- 未提供诊疗信息：本报告不包含任何诊断标准、治疗建议或个体化风险评估。

## 后续建议
1. 补充统计检验：对组间差异（年龄、血压、胆固醇、最大心率）进行显著性检验并报告置信区间，以判断差异的稳健性。
2. 开展建模与验证：在描述性分析基础上构建预测模型，并采用交叉验证与外部数据集验证性能；模型评估指标可参考准确率、精确率、召回率与 F1 分数等通用定义 [KB-3]。
3. 处理缺失与分层问题：明确主要血管数等特征的缺失机制，对样本量过小的年龄段（如 71–77 岁）合并分组或标注不稳定性。
4. 控制混杂因素：对性别、胸痛类型、年龄等变量进行分层或多变量分析，避免将单变量描述性差异误读为独立效应。
5. 规范数据字典：统一特征编码与取值范围说明（如胸痛类型、地中海贫血编码），便于结果复现与跨数据集比较 [KB-1][KB-2]。
