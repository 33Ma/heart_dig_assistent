# Cleveland 心脏风险数据分析报告

## 摘要
本报告基于 Cleveland 数据集（共 303 例样本）进行心脏病风险描述性分析。结果显示，样本总体心脏病阳性率为 45.9%（139/303 例），平均年龄 54.4 岁（范围 29–77 岁），平均静息血压 131.7 mmHg。分组比较显示，阳性组在年龄、静息血压、胆固醇上均高于阴性组，而最大心率低于阴性组。年龄分层中 61–70 岁组阳性率最高（58.9%），性别与胸痛类型分层亦呈现明显差异。

本报告仅为描述性统计分析，不构成任何诊疗结论或因果推断。

## 方法
- 数据来源：Cleveland 数据集，共 303 例样本，分为 5 个年龄组。
- 分析类型：心脏病风险描述性分析（kind 字段标注为“心脏病风险描述性分析”）。
- 分析内容：总体阳性率、年龄分层阳性率、风险因素比例、阳性组与阴性组组间指标比较、连续特征分布（最小值、四分位数、中位数、最大值）。
- 指标定义：阳性率指目标变量为“患有心脏病”的样本占比；组间差值指阳性组数值减去阴性组数值。
- 说明：本报告未涉及模型训练、预测性能评估或因果推断，仅呈现统计描述结果。

## 关键结果

### 总体指标
- 样本量：303 例（—）
- 心脏病阳性率：45.9%（139 / 303 例）
- 平均年龄：54.4 岁（范围 29–77 岁）
- 平均静息血压：131.7 mmHg（阴性组 129.3 mmHg）
- 阳性组最大心率：139.3 bpm（阴性组 158.4 bpm）

### 年龄分层阳性率
- 0–40 岁：样本数 18，阳性数 6，阳性率 33.3%
- 41–50 岁：样本数 76，阳性数 23，阳性率 30.3%
- 51–60 岁：样本数 130，阳性数 66，阳性率 50.8%
- 61–70 岁：样本数 73，阳性数 43，阳性率 58.9%
- 71–77 岁：样本数 6，阳性数 1，阳性率 16.7%

51–70 岁阳性率升至 50.8%–58.9%；71–77 岁组样本量仅 6 例，其阳性率（16.7%）的稳定性有限，解读需谨慎。

### 性别与胸痛类型
- 男性阳性率 55.3%，女性阳性率 25.8%。
- 胸痛类型 4 阳性率最高，达 72.9%。

### 风险因素比例
- 运动诱发心绞痛：比例 32.67%（99 例，32.7%）
- 空腹血糖异常：比例 14.85%（45 例，14.9%）
- ST 压低大于 0：比例 67.33%（204 例，67.3%）
- 主要血管数大于 0：比例 41.14%（123 / 299 例，41.1%）

### 组间比较（阳性组 vs 阴性组）
- 年龄：阳性组 56.6 岁，阴性组 52.6 岁（差值 +4.0）
- 静息血压：阳性组 134.6 mmHg，阴性组 129.3 mmHg（差值 +5.3）
- 胆固醇：阳性组 251.5 mg/dL，阴性组 242.6 mg/dL（差值 +8.8）
- 最大心率：阳性组 139.3 bpm，阴性组 158.4 bpm（差值 −19.1）

### 连续特征分布（最小值 / Q1 / 中位数 / Q3 / 最大值）
- 年龄：29.0 / 48.0 / 56.0 / 61.0 / 77.0
- 静息血压：94.0 / 120.0 / 130.0 / 140.0 / 200.0
- 胆固醇：126.0 / 211.0 / 241.0 / 275.0 / 564.0
- 最大心率：71.0 / 133.5 / 153.0 / 166.0 / 202.0
- ST 压低：0.0 / 0.0 / 0.8 / 1.6 / 6.2

## 解释
- 总体阳性率：样本中约 45.9% 的个体为心脏病阳性，接近半数，提示该数据集中阳性与阴性样本分布相对均衡。
- 年龄相关模式：阳性组平均年龄（56.6 岁）高于阴性组（52.6 岁），差值 +4.0 岁；年龄分层中 51–70 岁阳性率明显升高（50.8%–58.9%），而 41–50 岁组较低（30.3%）。该模式为描述性关联，不能解释为年龄导致心脏病。
- 心率差异：阳性组最大心率（139.3 bpm）低于阴性组（158.4 bpm），差值 −19.1 bpm，是本报告中组间差异幅度较大的指标之一。最大心率是运动负荷试验中的常见观测指标 [KB-1][KB-2]，但此处仅为组间均值比较，未做统计显著性检验。
- 血压与胆固醇：阳性组静息血压（134.6 mmHg）与胆固醇（251.5 mg/dL）均略高于阴性组，差值分别为 +5.3 mmHg 与 +8.8 mg/dL，差异幅度相对较小。
- 性别与胸痛类型：男性阳性率（55.3%）高于女性（25.8%）；胸痛类型 4 的阳性率（72.9%）为各分层中最高。胸痛类型与性别均为数据集中的分类特征 [KB-1][KB-2]，其分层差异需结合样本构成解读。
- 风险因素比例：ST 压低大于 0 的比例最高（67.3%），其次为主要血管数大于 0（41.1%）与运动诱发心绞痛（32.7%），空腹血糖异常比例最低（14.9%）。

## 局限性
- 描述性分析，无推断性结论：本报告未进行假设检验、置信区间估计或因果推断，所有组间差异仅为数值比较，不能据此判断统计学显著性。
- 未评估预测模型性能：本报告不包含模型训练、交叉验证或分类性能指标（如准确率、灵敏度、F1 等），无法评价任何预测方法的效力。
- 分层样本量不均衡：71–77 岁组仅 6 例，其阳性率（16.7%）代表性有限；部分分层（如性别、胸痛类型）未提供各组样本量明细，无法评估分层稳定性。
- 缺失值处理未说明：结构化结果未提供缺失值处理方式；参考知识显示该数据集部分特征存在缺失记录（如 ca 缺失比例 19.8%、thal 缺失比例 16.5%）[KB-2]，但本报告数据是否经过插补或剔除无法从给定结果确定。
- 单一数据集：结果仅基于 Cleveland 数据集，向其他人群或数据集的推广性无法确定。
- 指标口径限制：主要血管数大于 0 的比例以 299 例为分母（123/299），与总样本 303 例存在差异，原因未在给定结果中说明。

## 后续建议
1. 补充统计检验：对阳性组与阴性组的年龄、血压、胆固醇、最大心率差异进行显著性检验（如 t 检验或非参数检验），并报告效应量与置信区间。
2. 明确缺失值处理：说明 ca、thal 等特征的缺失处理策略，并评估其对分层结果的影响 [KB-2]。
3. 报告分层样本量：在性别、胸痛类型等分层中补充各组样本数与阳性数，提升结果可复核性。
4. 扩展分析维度：可结合特征重要性或可解释性方法（如 SHAP）分析各特征与目标的关联强度 [KB-1][KB-3]，但须与描述性结果明确区分。
5. 外部验证：在条件允许时，使用独立数据集验证上述描述性模式的稳定性 [KB-4]。
6. 声明用途边界：任何后续建模结果均应标注为研究性分析，不作为临床诊疗依据。
