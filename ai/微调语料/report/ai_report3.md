# Cleveland 心脏风险数据分析报告

## 摘要
本报告基于 Cleveland 数据集共 303 例样本，对心脏病风险相关指标进行描述性分析。结果显示，样本心脏病阳性率为 45.9%（139 / 303 例），平均年龄 54.4 岁（范围 29–77 岁），平均静息血压 131.7 mmHg。分组比较中，阳性组平均年龄、静息血压、胆固醇均高于阴性组，而最大心率低于阴性组（阳性组 139.3 bpm，阴性组 158.4 bpm）。年龄分层显示 51–70 岁人群阳性率较高（50.8%–58.9%），胸痛类型 4 的阳性率达 72.9%。

本报告仅为描述性统计结果，不构成任何诊疗结论。

## 方法
- 数据来源：Cleveland 数据集，共 303 例样本、5 个分组。
- 分析类型：心脏病风险描述性分析（非建模、非因果推断）。
- 分析内容：
  · 总体指标统计（平均年龄、阳性率、平均静息血压、阳性组最大心率）；
  · 年龄分层阳性率统计；
  · 风险因素比例统计（运动诱发心绞痛、空腹血糖异常、ST 压低大于 0、主要血管数大于 0）；
  · 阳性组与阴性组组间指标比较；
  · 连续特征分布（最小值、Q1、中位数、Q3、最大值）。
- 说明：本报告未包含模型训练、显著性检验或预测性能评估，相关结论无法从现有结果中得出。

## 关键结果

### 总体指标
- 样本量：303 例
- 心脏病阳性率：45.9%（139 / 303 例）
- 平均年龄：54.4 岁（范围 29–77 岁）
- 平均静息血压：131.7 mmHg（阴性组 129.3 mmHg）
- 阳性组最大心率：139.3 bpm（阴性组 158.4 bpm）

### 年龄分层阳性率
- 0–40 岁：样本 18 例，阳性 6 例，阳性率 33.3%
- 41–50 岁：样本 76 例，阳性 23 例，阳性率 30.3%
- 51–60 岁：样本 130 例，阳性 66 例，阳性率 50.8%
- 61–70 岁：样本 73 例，阳性 43 例，阳性率 58.9%
- 71–77 岁：样本 6 例，阳性 1 例，阳性率 16.7%

### 风险因素比例
- ST 压低大于 0：67.3%（204 例）
- 主要血管数大于 0：41.1%（123 / 299 例）
- 运动诱发心绞痛：32.7%（99 例）
- 空腹血糖异常：14.9%（45 例）

### 组间比较（阳性组 vs 阴性组）
- 年龄：阳性组 56.6 岁 vs 阴性组 52.6 岁（差值 +4.0）
- 静息血压：阳性组 134.6 mmHg vs 阴性组 129.3 mmHg（差值 +5.3）
- 胆固醇：阳性组 251.5 mg/dL vs 阴性组 242.6 mg/dL（差值 +8.8）
- 最大心率：阳性组 139.3 bpm vs 阴性组 158.4 bpm（差值 -19.1）

### 连续特征分布（最小值 / Q1 / 中位数 / Q3 / 最大值）
- 年龄（岁）：29.0 / 48.0 / 56.0 / 61.0 / 77.0
- 静息血压（mmHg）：94.0 / 120.0 / 130.0 / 140.0 / 200.0
- 胆固醇（mg/dL）：126.0 / 211.0 / 241.0 / 275.0 / 564.0
- 最大心率（bpm）：71.0 / 133.5 / 153.0 / 166.0 / 202.0
- ST 压低（mV）：0.0 / 0.0 / 0.8 / 1.6 / 6.2

### 性别与胸痛类型
- 性别：男性阳性率 55.3%，女性阳性率 25.8%。
- 胸痛类型：类型 4 阳性率最高，达 72.9%。

## 解释
- 总体阳性率：样本中 45.9% 为心脏病阳性，说明该数据集中阳性与阴性样本接近均衡。
- 年龄相关分布：阳性组平均年龄（56.6 岁）高于阴性组（52.6 岁），差值 +4.0 岁；年龄分层中 51–60 岁与 61–70 岁阳性率分别为 50.8% 和 58.9%，为各年龄段中较高水平。需注意 71–77 岁组仅 6 例，其 16.7% 的阳性率样本量过小，解释时应谨慎。
- 心率差异：阳性组最大心率（139.3 bpm）明显低于阴性组（158.4 bpm），差值 -19.1 bpm，是本报告中组间差异幅度较大的指标之一。最大心率为运动负荷相关指标，其含义可参考心脏功能评估相关概念 [KB-1][KB-2]。
- 血压与胆固醇：阳性组静息血压（134.6 mmHg）与胆固醇（251.5 mg/dL）均略高于阴性组（分别为 129.3 mmHg、242.6 mg/dL），差值分别为 +5.3 mmHg 与 +8.8 mg/dL。
- 风险因素比例：ST 压低大于 0 的比例最高（67.3%），其次为主要血管数大于 0（41.1%）与运动诱发心绞痛（32.7%）；空腹血糖异常比例最低（14.9%）。ST 段压低与运动诱发心绞痛属于心脏负荷评估中的常见观察指标 [KB-1][KB-3]。
- 性别与胸痛类型：男性阳性率（55.3%）高于女性（25.8%）；胸痛类型 4（无症状）阳性率最高（72.9%），该结果与“无症状者风险更低”的直觉相反，具体机制无法从本描述性结果中确定。

## 局限性
- 本报告为描述性统计，未进行显著性检验、混杂因素控制或因果推断，组间差值不代表因果效应。
- 部分分组样本量较小（如 71–77 岁组仅 6 例），其阳性率稳定性有限。
- 主要血管数大于 0 的比例基于 299 例计算（123 / 299），与总样本 303 例存在样本量差异，可能涉及缺失值，具体缺失情况未在结果中说明。
- 报告未包含模型预测性能（如准确率、灵敏度等），无法据此评估风险预测能力。
- 数据集来源为 Cleveland 单中心数据，外推至其他人群需谨慎。
- 本报告不构成诊疗结论，任何临床判断需由专业医务人员结合完整检查作出。

## 后续建议
- 对年龄、最大心率、ST 压低等组间差异较明显的指标，建议在控制混杂因素后开展进一步统计分析（如显著性检验或多因素分析）。
- 对样本量过小的年龄段（如 71–77 岁）补充样本或合并分组后再行比较。
- 明确并报告各特征的缺失情况（如主要血管数），以保证比例统计口径一致。
- 如需评估风险预测能力，可在本描述性分析基础上另行构建并验证预测模型，报告相应性能指标。
- 所有分析结果应仅用于研究目的，临床解读需由专业人员完成。
