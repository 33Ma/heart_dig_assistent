# Cleveland 心脏风险数据分析报告

## 摘要
本报告基于 Cleveland 数据集共 303 例样本，对心脏病阳性率及相关特征进行描述性分析。主要发现如下：
- 总体心脏病阳性率为 45.9%（139 / 303 例）。
- 样本平均年龄为 54.4 岁（范围 29–77 岁）。
- 阳性组平均最大心率为 139.3 bpm，低于阴性组的 158.4 bpm。
- 阳性组平均静息血压为 134.6 mmHg，高于阴性组的 129.3 mmHg。
- 男性阳性率（55.3%）高于女性（25.8%）；胸痛类型 4 的阳性率最高（72.9%）。

说明：本报告仅为描述性统计分析，不构成任何诊疗结论或因果推断。

## 方法
- 数据来源：Cleveland 数据集，共 303 例样本、5 个分组。
- 分析类型：心脏病风险描述性分析（非建模、非预测验证）。
- 分析内容：总体阳性率、年龄分层阳性率、风险因素比例、阳性组与阴性组组间比较、连续特征分布（最小值、四分位数、中位数、最大值）。
- 指标定义：阳性率指目标变量为“患有心脏病”的样本占比；组间差值以阳性组减阴性组计算。

## 关键结果

### 1. 总体指标
- 样本量：303 例（—）
- 心脏病阳性率：45.9%（139 / 303 例）
- 平均年龄：54.4 岁（范围 29–77 岁）
- 平均静息血压：131.7 mmHg（阴性组 129.3 mmHg）
- 阳性组最大心率：139.3 bpm（阴性组 158.4 bpm）

### 2. 年龄分层阳性率
- 0–40 岁：样本 18 例，阳性 6 例，阳性率 33.3%
- 41–50 岁：样本 76 例，阳性 23 例，阳性率 30.3%
- 51–60 岁：样本 130 例，阳性 66 例，阳性率 50.8%
- 61–70 岁：样本 73 例，阳性 43 例，阳性率 58.9%
- 71–77 岁：样本 6 例，阳性 1 例，阳性率 16.7%
（注：51–70 岁两个年龄段阳性率升至 50.8%–58.9%；71–77 岁组样本量仅 6 例，其阳性率（16.7%）解释力有限。）

### 3. 风险因素比例
- 运动诱发心绞痛：32.67%（99 例，32.7%）
- 空腹血糖异常：14.85%（45 例，14.9%）
- ST 压低大于 0：67.33%（204 例，67.3%）
- 主要血管数大于 0：41.14%（123 / 299，41.1%）

### 4. 阳性组与阴性组组间比较（差值：阳性 - 阴性）
- 年龄：阳性组 56.6 岁 vs 阴性组 52.6 岁（差值 +4.0）
- 静息血压：阳性组 134.6 mmHg vs 阴性组 129.3 mmHg（差值 +5.3）
- 胆固醇：阳性组 251.5 mg/dL vs 阴性组 242.6 mg/dL（差值 +8.8）
- 最大心率：阳性组 139.3 bpm vs 阴性组 158.4 bpm（差值 -19.1）

### 5. 连续特征分布（最小值 / Q1 / 中位数 / Q3 / 最大值）
- 年龄（岁）：29.0 / 48.0 / 56.0 / 61.0 / 77.0
- 静息血压（mmHg）：94.0 / 120.0 / 130.0 / 140.0 / 200.0
- 胆固醇（mg/dL）：126.0 / 211.0 / 241.0 / 275.0 / 564.0
- 最大心率（bpm）：71.0 / 133.5 / 153.0 / 166.0 / 202.0
- ST 压低（mV）：0.0 / 0.0 / 0.8 / 1.6 / 6.2

## 解释
- 年龄：阳性组平均年龄比阴性组高 4.0 岁；年龄分层显示 51–70 岁阳性率较高，但 71–77 岁组样本仅 6 例，不宜据此得出趋势性结论。
- 最大心率：阳性组平均最大心率比阴性组低 19.1 bpm，是本数据中组间差异较明显的指标之一。该差异为描述性统计结果，不能据此推断因果或用于个体判断。
- 静息血压与胆固醇：阳性组静息血压高 5.3 mmHg、胆固醇高 8.8 mg/dL，差异幅度相对有限，需结合分布与样本特征谨慎解读。
- 性别与胸痛类型：男性阳性率 55.3%、女性 25.8%；胸痛类型 4 阳性率 72.9%，为各胸痛类型中最高。上述均为样本内比例描述。
- 风险因素：ST 压低大于 0 的比例最高（67.3%），其次为主要血管数大于 0（41.1%）与运动诱发心绞痛（32.7%），空腹血糖异常比例最低（14.9%）。

## 局限性
- 本报告为描述性分析，未进行建模、显著性检验或因果推断，组间差值不代表风险效应。
- 部分分层样本量较小（如 71–77 岁组仅 6 例），对应阳性率的稳定性有限。
- 主要血管数指标的分母为 299（非 303），存在少量缺失，相关比例的解释需注意。
- 数据仅来自 Cleveland 数据集，结论不宜外推至其他人群或临床场景。
- 未提供置信区间、缺失值处理细节及混杂因素控制信息，无法评估估计精度。

## 后续建议
1. 对组间差异补充统计检验与置信区间，以评估差异的稳定性。
2. 对小样本分层（如 71–77 岁组）谨慎解读，必要时合并分组或标注样本量限制。
3. 明确主要血管数等存在缺失的指标的缺失处理方式，并在报告中统一分母口径。
4. 如需进一步分析，可在描述性结果基础上开展多因素建模，但须与当前描述性结论明确区分。
5. 所有结果仅用于研究与数据分析目的，不作为诊疗依据。
