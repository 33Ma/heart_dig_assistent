# Cleveland 心脏风险数据分析报告

## 摘要
本报告基于 Cleveland 数据集共 303 例样本，对心脏病阳性率及其相关特征进行描述性分析。主要发现如下：
- 总体心脏病阳性率为 45.9%（139 / 303 例）。
- 样本平均年龄为 54.4 岁（范围 29–77 岁）。
- 阳性组平均最大心率为 139.3 bpm，低于阴性组的 158.4 bpm（差值 −19.1 bpm）。
- 阳性组平均静息血压为 134.6 mmHg，高于阴性组的 129.3 mmHg（差值 +5.3 mmHg）。
- 年龄分层中，61–70 岁组阳性率最高（58.9%）；胸痛类型 4 的阳性率达 72.9%。

说明：本报告仅为描述性统计分析，不构成任何诊疗结论或因果推断。

## 方法
- 数据来源：Cleveland 数据集，共 303 条记录、5 个分组。
- 分析类型：心脏病风险描述性分析（非建模、非预测）。
- 分析内容：
  - 总体阳性率计算；
  - 按年龄段（0–40、41–50、51–60、61–70、71–77）分层统计阳性率；
  - 风险因素比例统计（运动诱发心绞痛、空腹血糖异常、ST 压低大于 0、主要血管数大于 0）；
  - 阳性组与阴性组在年龄、静息血压、胆固醇、最大心率上的组间比较；
  - 连续特征的分布描述（最小值、Q1、中位数、Q3、最大值）。
- 概念说明：数据集中各特征的含义与取值定义可参考相关文献中的特征表描述 [KB-1][KB-2][KB-3]。

## 关键结果

### 1. 总体情况
- 样本量：303 例
- 心脏病阳性数：139 例
- 心脏病阳性率：45.9%（139 / 303）
- 平均年龄：54.4 岁（范围 29–77 岁）
- 平均静息血压：131.7 mmHg（阴性组 129.3 mmHg）

### 2. 年龄分层阳性率
- 0–40 岁：样本 18 例，阳性 6 例，阳性率 33.3%
- 41–50 岁：样本 76 例，阳性 23 例，阳性率 30.3%
- 51–60 岁：样本 130 例，阳性 66 例，阳性率 50.8%
- 61–70 岁：样本 73 例，阳性 43 例，阳性率 58.9%
- 71–77 岁：样本 6 例，阳性 1 例，阳性率 16.7%
（注：51–70 岁阳性率升至 50.8%–58.9%；71–77 岁组样本量仅 6 例，其阳性率 16.7% 解释力有限。）

### 3. 风险因素比例
- ST 压低大于 0：67.3%（204 例）
- 主要血管数大于 0：41.1%（123 / 299 例）
- 运动诱发心绞痛：32.7%（99 例）
- 空腹血糖异常：14.9%（45 例）

### 4. 组间比较（阳性组 vs 阴性组）
- 年龄：56.6 岁 vs 52.6 岁（差值 +4.0）
- 静息血压：134.6 mmHg vs 129.3 mmHg（差值 +5.3）
- 胆固醇：251.5 mg/dL vs 242.6 mg/dL（差值 +8.8）
- 最大心率：139.3 bpm vs 158.4 bpm（差值 -19.1）

### 5. 连续特征分布（最小值 / Q1 / 中位数 / Q3 / 最大值）
- 年龄：29.0 / 48.0 / 56.0 / 61.0 / 77.0
- 静息血压：94.0 / 120.0 / 130.0 / 140.0 / 200.0
- 胆固醇：126.0 / 211.0 / 241.0 / 275.0 / 564.0
- 最大心率：71.0 / 133.5 / 153.0 / 166.0 / 202.0
- ST 压低：0.0 / 0.0 / 0.8 / 1.6 / 6.2

### 6. 性别与胸痛类型
- 男性阳性率 55.3%，女性阳性率 25.8%。
- 胸痛类型 4 阳性率最高，达 72.9%。

## 解释
- 总体阳性率：本样本中约 45.9% 的记录为心脏病阳性，接近半数，说明该数据集阳性与阴性样本分布相对均衡。
- 年龄：阳性组平均年龄（56.6 岁）高于阴性组（52.6 岁），差值为 +4.0 岁；年龄分层显示 51–70 岁区间阳性率较高，但 71–77 岁组样本量过小（6 例），不宜据此下结论。
- 最大心率：阳性组最大心率明显低于阴性组（139.3 vs 158.4 bpm，差值 −19.1 bpm），是本报告中组间差异较明显的指标之一。该特征在相关文献中被列为重要特征 [KB-1][KB-3]。
- 静息血压与胆固醇：阳性组两项指标均略高于阴性组（血压 +5.3 mmHg、胆固醇 +8.8 mg/dL），但本报告未提供显著性检验结果，不能判断差异是否具有统计学意义。
- 风险因素：ST 压低大于 0 的比例最高（67.3%），其次为主要血管数大于 0（41.1%）和运动诱发心绞痛（32.7%）；空腹血糖异常比例最低（14.9%）。
- 性别与胸痛类型：男性阳性率（55.3%）高于女性（25.8%）；胸痛类型 4 的阳性率（72.9%）在各胸痛类型中最高。上述均为描述性对比，不构成因果解释。

## 局限性
- 描述性分析：本报告仅提供统计描述，未进行假设检验、建模或预测，无法评估各因素与心脏病之间的独立效应或因果关系。
- 样本量不均衡：71–77 岁组仅 6 例，其阳性率（16.7%）稳定性差，不宜与其他年龄段直接比较。
- 缺失信息：主要血管数指标的分母为 299（而非 303），提示存在少量缺失；本报告未获得缺失机制说明。
- 未提供显著性检验：组间差值（年龄、血压、胆固醇、最大心率）均未附统计检验结果，差异是否显著无法确定。
- 单数据集：结果仅基于 Cleveland 数据集，外推至其他人群需谨慎。
- 未包含模型性能：本报告不涉及任何分类模型的准确率、灵敏度等性能指标。

## 后续建议
1. 补充统计检验：对组间差异（年龄、血压、胆固醇、最大心率）进行显著性检验，以判断差异是否具有统计学意义。
2. 处理小样本分层：对 71–77 岁等小样本组谨慎解读，或合并相邻年龄段后重新统计。
3. 明确缺失机制：核查主要血管数等特征的缺失情况（299 vs 303），说明缺失处理方式。
4. 扩展分析维度：可在描述性分析基础上，结合特征选择与可解释性方法进一步分析特征贡献 [KB-1][KB-3]，但相关结论需以实际建模结果为准。
5. 多数据集验证：如需外推结论，建议在其他心脏疾病数据集上重复分析 [KB-4]。
