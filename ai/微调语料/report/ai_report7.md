# Cleveland 心脏风险数据分析报告

## 摘要
本报告基于 Cleveland 数据集的结构化分析结果，对 303 例样本的心脏病风险相关特征进行描述性分析。主要发现如下：
- 样本总体心脏病阳性率为 45.9%（139 / 303 例）。
- 平均年龄为 54.4 岁（范围 29–77 岁）。
- 阳性组与阴性组在年龄、静息血压、胆固醇和最大心率上存在组间差异：阳性组年龄更高（+4.0 岁）、静息血压更高（+5.3 mmHg）、胆固醇更高（+8.8）、最大心率更低（-19.1 bpm）。
- 年龄分层中，51–70 岁人群阳性率升至 50.8%–58.9%；胸痛类型 4 的阳性率最高，为 72.9%。
- 性别差异明显：男性阳性率 55.3%，女性 25.8%。

说明：本报告仅为描述性统计分析，不构成任何诊疗结论或个体化医学建议。

## 方法
### 数据来源与规模
- 数据集：Cleveland 数据集。
- 样本量：303 例（trajectory_count = 303）。
- 分组数：5 组（group_count = 5，对应年龄段分层）。
- 分析类型：心脏病风险描述性分析。

### 分析内容
依据结构化分析结果，本报告涵盖以下分析维度：
1. 总体指标：平均年龄、心脏病阳性率、平均静息血压、阳性组最大心率。
2. 年龄分层：按 0–40、41–50、51–60、61–70、71–77 岁五组统计样本数、阳性数与阳性率。
3. 风险因素比例：运动诱发心绞痛、空腹血糖异常、ST 压低大于 0、主要血管数大于 0 的占比。
4. 组间比较：阳性组与阴性组在年龄、静息血压、胆固醇、最大心率上的差值。
5. 连续特征分布：年龄、静息血压、胆固醇、最大心率、ST 压低的五数概括（最小值、Q1、中位数、Q3、最大值）。

### 指标定义说明
心脏病阳性率指目标变量为阳性（患有心脏病）的样本占全部样本的比例。相关特征的含义可参考心脏疾病预测文献中的变量说明，如年龄、性别、胸痛类型、静息血压、血清胆固醇、最大心率、运动诱发心绞痛、ST 段压低、主要血管数等 [KB-1][KB-2][KB-3]。

## 关键结果

### 总体指标
- 平均年龄：54.4 岁（范围 29–77 岁）
- 心脏病阳性率：45.9%（139 / 303 例）
- 平均静息血压：131.7 mmHg（阴性组 129.3 mmHg）
- 阳性组最大心率：139.3 bpm（阴性组 158.4 bpm）

### 年龄分层阳性率
- 0–40 岁：样本数 18，阳性数 6，阳性率 33.3%
- 41–50 岁：样本数 76，阳性数 23，阳性率 30.3%
- 51–60 岁：样本数 130，阳性数 66，阳性率 50.8%
- 61–70 岁：样本数 73，阳性数 43，阳性率 58.9%
- 71–77 岁：样本数 6，阳性数 1，阳性率 16.7%

注：71–77 岁组样本数仅 6 例，阳性率 16.7% 的稳定性有限，解读需谨慎。

### 风险因素比例
- 运动诱发心绞痛：比例 32.67%（99 例，32.7%）
- 空腹血糖异常：比例 14.85%（45 例，14.9%）
- ST 压低大于 0：比例 67.33%（204 例，67.3%）
- 主要血管数大于 0：比例 41.14%（123 / 299，41.1%）

注：主要血管数大于 0 的比例基于 299 例计算（分母与总样本 303 例不一致），可能存在缺失值，具体缺失原因未在结果中说明。

### 组间比较（阳性组 vs 阴性组）
- 年龄：阳性组 56.6 岁，阴性组 52.6 岁（差值 +4.0）
- 静息血压：阳性组 134.6 mmHg，阴性组 129.3 mmHg（差值 +5.3）
- 胆固醇：阳性组 251.5，阴性组 242.6（差值 +8.8）
- 最大心率：阳性组 139.3 bpm，阴性组 158.4 bpm（差值 -19.1）

### 连续特征分布（五数概括）
- 年龄：最小值 29.0 / Q1 48.0 / 中位数 56.0 / Q3 61.0 / 最大值 77.0
- 静息血压：最小值 94.0 / Q1 120.0 / 中位数 130.0 / Q3 140.0 / 最大值 200.0
- 胆固醇：最小值 126.0 / Q1 211.0 / 中位数 241.0 / Q3 275.0 / 最大值 564.0
- 最大心率：最小值 71.0 / Q1 133.5 / 中位数 153.0 / Q3 166.0 / 最大值 202.0
- ST 压低：最小值 0.0 / Q1 0.0 / 中位数 0.8 / Q3 1.6 / 最大值 6.2

### 性别与胸痛类型
- 男性阳性率 55.3%，女性阳性率 25.8%。
- 胸痛类型 4 的阳性率最高，达 72.9%。

## 解释
以下解释严格基于上述统计结果，仅描述数据中的关联模式，不推断因果关系或临床结论。
1. 总体阳性率接近半数：样本阳性率为 45.9%，说明该数据集中阳性与阴性样本数量相对均衡，适合作为二分类分析的描述性基础。
2. 年龄与阳性率的关联呈非单调模式：阳性率在 41–50 岁组最低（30.3%），在 51–60 岁（50.8%）和 61–70 岁（58.9%）明显升高，而 71–77 岁组降至 16.7%。但 71–77 岁组仅 6 例样本，该组阳性率不宜作为稳定趋势解读。整体上，51–70 岁是阳性率较高的区间。
3. 组间差异方向一致：阳性组平均年龄更高（+4.0 岁）、静息血压更高（+5.3 mmHg）、胆固醇更高（+8.8）、最大心率更低（-19.1 bpm）。这些差异均为组间均值比较，未提供显著性检验结果，不能据此判断统计学显著性。
4. 性别差异明显：男性阳性率（55.3%）高于女性（25.8%），但该结果未控制年龄、胸痛类型等其他因素的混杂影响，仅为单变量描述。
5. 胸痛类型 4 阳性率突出：胸痛类型 4 的阳性率达 72.9%，为各胸痛类型中最高。胸痛类型的分类含义可参考相关文献中的变量定义 [KB-1][KB-4]。
6. 风险因素比例：ST 压低大于 0 的比例最高（67.3%），其次为主要血管数大于 0（41.1%）和运动诱发心绞痛（32.7%），空腹血糖异常比例最低（14.9%）。这些比例描述的是样本中相应指标异常或存在的占比，不代表人群患病风险。

## 局限性
1. 仅为描述性分析：本报告未包含统计显著性检验、效应量或置信区间，组间差异与分层阳性率均不能用于推断统计学显著性。
2. 未控制混杂因素：性别、年龄、胸痛类型等结果均为单变量描述，未进行多因素调整，变量间的关联可能相互混杂。
3. 小样本分层不稳定：71–77 岁组仅 6 例样本，其阳性率（16.7%）代表性有限；0–40 岁组仅 18 例，同样需谨慎解读。
4. 分母不一致：主要血管数大于 0 的比例基于 299 例计算，与总样本 303 例不一致，提示存在缺失值，但结果未说明缺失处理方式。
5. 数据来源单一：结果仅基于 Cleveland 数据集，未提供外部验证，结论的外推性受限。
6. 无诊疗结论：本报告不包含任何诊断、治疗或个体风险预测结论，不能用于临床决策。

## 后续建议
1. 补充统计检验：对组间差异（年龄、血压、胆固醇、最大心率）进行显著性检验并报告效应量与置信区间，以判断差异是否具有统计学意义。
2. 开展多因素分析：在控制年龄、性别等混杂因素的前提下，评估各特征与阳性结果的独立关联。
3. 处理缺失值并说明口径：明确主要血管数等变量的缺失情况与处理方式，统一分母口径。
4. 谨慎对待小样本分层：对 71–77 岁等小样本组，建议合并分组或标注不确定性，避免过度解读。
5. 外部验证：如需推广结论，应在独立数据集上进行验证。
6. 明确分析边界：后续任何建模或预测工作均应声明其研究性质，不得直接转化为诊疗建议。
